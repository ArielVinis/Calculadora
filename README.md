# 📐 Calculadora em Java (Projeto de Exercício)

Este é um projeto simples de **calculadora em Java**, desenvolvido com o objetivo de exercitar os fundamentos da linguagem: leitura de entrada com `Scanner`, estruturas de controle (`switch`) e formatação de saída com `System.out.printf`.

---

## 🚀 Como funciona

A calculadora:

1. Solicita dois números do usuário.
2. Pede a escolha de uma operação matemática básica: `+`, `-`, `*` ou `/`.
3. Realiza o cálculo e imprime o resultado de três formas:
   - Forma simples (`System.out.println`)
   - Forma formatada (`System.out.printf`)

---

## 📦 Tecnologias usadas

- **Java JDK 17** (ou superior)
- Nenhuma biblioteca externa
- Execução via terminal ou IDE (IntelliJ, Eclipse, VSCode)

---

## 💻 Execução

### Compilação:

```bash
javac Calculadora.java
```

### Execução:

```bash
java Calculadora
```

---

## 📋 Exemplo de uso

```bash
Digite o primeiro número: 5
Digite o segundo número: 3
Digite uma operação (+, -, *, /): *

Resultado (println):
5.0 * 3.0 = 15.0

Resultado (printf):
(5.00) (*) (3.00) = (15.00)
```

---

## 🎯 Objetivo

Este projeto foi criado para **fixar conceitos fundamentais de Java**, especialmente:

- Tipos primitivos (`double`, `char`)
- Entrada de dados com `Scanner`
- Controle condicional com `switch`
- Impressão formatada com `printf`
- Boas práticas na separação lógica do código
